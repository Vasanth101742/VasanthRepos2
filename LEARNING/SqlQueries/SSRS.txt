1.you can place a chart (or breakup data table say A) inside a rectangle and that rectangle can be placed into another table say B.
Now this B Table can be customized by grouping on specific column so that details symbol will be converted into grouping symbol in the B Table.
now if you preview this report. it wil show set of charts or tables(say A Table) for each group specified in table B.

But in case of Matrix , it can be done simply by 
i.grouping the matrix rows based on some column and then
ii.placing the chart or table inside a matrix cell.

here what is the need of rectangle is we can accomodate a title textbox along with the table A while placing inside the Table B or inside a matrix.

for example, if month parameter will be selected based on the year parameter then first create a year parameter and related year dataset.
then create a month parameter and related month dataset. now in this month dataset query you can use @year in the where clause.

if ordering mismatch occurs then you will get the error as forward dependencies is invalid.

Question: Report containing main Report and sub report.
when user clicks an empty box in a main report, it wont go to the sub report. instead, it throws an error. how to eliminate this and display the text as 
'Sorry No data Availabe for this selection.'


Step 1:  create a new parameter  @Data_Availability in the sub report

step 2: in the subreport, create a new dataset with the below structure.

if not exists(select * from table_name where col1=@col1)
begin
set @Data_Availability=False
end

if exists(select * from table_name where col1=@col1)
begin
set @Data_Availability=TRUE
end


Step 3: now create a new tablix or table with the txt msg as 'Sorry No Data Found' in the report pane.

Step 4: now in the regular tablix,choose visibility as show or hide based on expression and create an exp iif(@Data_Availability=TRUE,false,true)
Step 5: now in the newly created tablix,choose visibility as show or hide based on expression and create an exp iif(@Data_Availability=TRUE,true,false)
